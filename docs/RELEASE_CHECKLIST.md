# リリース前チェックリスト

ストアへ提出する前に実機（またはエミュレータ/シミュレータ）で確認する項目。
ユニットテストはネイティブモジュール（expo-media-library, expo-image-picker, expo-file-system など）を
モックしているため、**ライブラリの更新で入口の挙動が変わった種類のデグレは検出できない**。
特にExpo/React Nativeのメジャー更新を含むリリースでは、下記の「ネイティブ経路」を必ず実機で通すこと。

バージョン・ストア申告まわりは `docs/STORE_SUBMISSION_ANALYTICS.md` の「提出時チェックリスト」を参照。

## 自動チェック（コミット前）

- [ ] `npx tsc --noEmit`
- [ ] `yarn lint`（`expo-media-library` ルートimport禁止ルールを含む）
- [ ] `yarn test`

## ネイティブ経路のスモークテスト（iOS / Android 両方）

### 写真
- [ ] 写真フィールドの **カメラボタン** で撮影 → サムネイルが出て保存ボタンが有効になる → 保存 → 開き直して写真が残っている
      （0.6.0〜0.6.7で `expo-media-library` の入口変更により保存されなかった。[CHANGELOG 0.6.8]）
- [ ] 撮影した写真が端末のカメラロールにも入っている
- [ ] **Android**: 開発者オプション「アクティビティを保持しない」をONにして撮影 → 編集画面が開き直り写真が付いている
      （カメラ起動中にMainActivityが破棄されると、Reactツリーが作り直されてボトムシートが閉じ撮影結果が失われる。
      復帰は `usePendingPhotoCapture` ＋ expo-modules-core のパッチで実現。[docs/RELEASE_CHECKLIST.md 参照元: 0.6.8]）
- [ ] 写真フィールドの **ライブラリから選択** で追加 → 保存 → 再表示
- [ ] 写真をタップして拡大表示・削除ができる
- [ ] 軌跡サマリーに軌跡上の写真が表示される（iOS: Live Photo を含む）

### ファイル入出力
- [ ] GPX / GeoJSON / CSV のインポート（共有シートからの受け取りを含む）
- [ ] エクスポート（ZIP生成・共有）と、写真付きレイヤのエクスポート（KMZ）
- [ ] 軌跡サマリー・データ一覧のエクスポートで、開始前の確認・進捗表示・中止が動き、保存先の選択肢が押せる
- [ ] PDF出力（進捗表示・中止）

### 位置情報・地図
- [ ] 現在地取得、軌跡記録の開始/停止（バックグラウンド含む）
- [ ] タイルのダウンロードと、オフラインでの表示
- [ ] PMTiles（ラスタ/ベクタ）の表示（Android は R8 ビルドで確認）
- [ ] 長時間（15分以上）の軌跡記録：画面OFFのまま移動し、アプリを開き直しても記録が途切れず点が重複しない
      （位置情報ライブラリ react-native-background-geolocation を更新したリリースでは必須）
- [ ] 長押しの標高表示、可視領域の作成、標高データのダウンロード（標高はMapterhornをネイティブでデコード）
- [ ] 2本指で地図が回転し、コンパスのタップで北が上に戻る。回転中も現在地マーカー・線の矢印が実際の方角を向く。作図・ツール使用中は回転しない
- [ ] PDF出力にPMTilesの地図が入る

### 3D表示・眺望（Android は実機で必ず確認。シミュレータとGPUが異なる）
- [ ] 3D表示に切り替えて、地形・レイヤのデータ・ベクタPMTilesが描かれ、タップで属性が出る
- [ ] 3Dで現在地マーカー・記録中の軌跡・軌跡リプレイが表示される。回転した2D地図から切り替えると向きを引き継ぐ
- [ ] Google標準地図/衛星写真を選んだ状態で3Dにすると地理院地図に置き換わる。GEBCO海底地形図が立体表示される
- [ ] 長押しメニューの「ここからの眺望」「現在地からの眺望」が開き、山名・望遠/広角・視点の高さ変更が動く
- [ ] 眺望でコンパスをタップすると視線が端末の向きに追従し、「現在地からの眺望」は移動に合わせて立ち位置も追従する
- [ ] 3Dを開いたまましばらく操作して、極端なカクつき・発熱・クラッシュがない

### 外部GNSS受信機（AndroidはR8ビルドで確認。iOSはBLEのみ）
- [ ] USB（OTG・Androidのみ）とBLE（Nordic UART）のそれぞれで受信機に接続でき、GPS設定画面に測位品質・衛星数が出る
- [ ] NTRIPに接続して受信量が増え、単独 → FLOAT → FIX と遷移する（VRSはGGA送信ON、単一基準局はOFFでも可）
- [ ] 地図のバッジ表示、現在地ポイントの記録（coordsに`gnss`が入る）、平均化して追加
- [ ] 画面OFF中も軌跡が記録され続け、ケーブルを抜く/電源を切ると「内蔵GPS」に戻る
- [ ] iOS: 初回のスキャンでBluetoothの権限ダイアログが出る（起動直後には出ない）。拒否・Bluetoothオフでエラーが表示される
- [ ] 起動し直す・前面に戻すと前回の受信機へ自動で再接続し、「切断」した後は再接続しない

### データ編集
- [ ] レイヤ設定で属性名を変更しても値が残り、ラベル・色分けも追従する
