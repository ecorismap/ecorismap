# リリース前チェックリスト

ストアへ提出する前に実機（またはエミュレータ/シミュレータ）で確認する項目。
ユニットテストはネイティブモジュール（expo-media-library, expo-image-picker, expo-file-system など）を
モックしているため、**ライブラリの更新で入口の挙動が変わった種類のデグレは検出できない**。
特にExpo/React Nativeのメジャー更新を含むリリースでは、下記の「ネイティブ経路」を必ず実機で通すこと。

バージョン・ストア申告まわりは `docs/STORE_SUBMISSION_ANALYTICS.md` の「提出時チェックリスト」を参照。

## 自動チェック（コミット前）

- [ ] `npx tsc --noEmit`
- [ ] `yarn lint`（`expo-media-library` ルートimport禁止ルールを含む）
- [ ] `yarn test`

## ネイティブ経路のスモークテスト（iOS / Android 両方）

### 写真
- [ ] 写真フィールドの **カメラボタン** で撮影 → サムネイルが出て保存ボタンが有効になる → 保存 → 開き直して写真が残っている
      （0.6.0〜0.6.7で `expo-media-library` の入口変更により保存されなかった。[CHANGELOG 0.6.8]）
- [ ] 撮影した写真が端末のカメラロールにも入っている
- [ ] 写真フィールドの **ライブラリから選択** で追加 → 保存 → 再表示
- [ ] 写真をタップして拡大表示・削除ができる
- [ ] 軌跡サマリーに軌跡上の写真が表示される（iOS: Live Photo を含む）

### ファイル入出力
- [ ] GPX / GeoJSON / CSV のインポート（共有シートからの受け取りを含む）
- [ ] エクスポート（ZIP生成・共有）と、写真付きレイヤのエクスポート（KMZ）
- [ ] PDF出力（進捗表示・中止）

### 位置情報・地図
- [ ] 現在地取得、軌跡記録の開始/停止（バックグラウンド含む）
- [ ] タイルのダウンロードと、オフラインでの表示
- [ ] PMTiles（ラスタ/ベクタ）の表示（Android は R8 ビルドで確認）

### 認証・同期
- [ ] ログイン（Google / 組織アカウント）とログアウト
- [ ] プロジェクトのアップロード / ダウンロード（暗号化の往復）

## 更新情報・ドキュメント
- [ ] アプリ内「更新情報」が今回の内容になっている（OS固有の修正は載せない）
- [ ] `CHANGELOG.md` の日付を確定
- [ ] マニュアル（websiteリポジトリ）の追従が必要なら反映
