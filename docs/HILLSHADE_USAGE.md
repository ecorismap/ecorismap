# 陰影起伏図(全方位対応) の使い方

地図一覧では「陰影起伏図(全方位対応)」として表示されます。
既定で入っている「陰影起伏図」は地理院が配信する完成品のラスタタイルで、別物です。

標高タイルから地形の陰影を計算して表示する機能です。

従来の陰影起伏図は光源方位に依存するため、地図を180度回すと凹凸が反転して見えました。
また光源と平行な走向の谷は明暗差を持たず、構造的に見落とされる弱点もありました。
現在の方式は式に光源が現れないため、**地図をどの向きに回しても見え方が変わりません**。

## 使い方

地図設定画面の URL に `hillshade://` を付けて標高タイルの URL を指定します。

```
hillshade://https://tiles.gsj.jp/tiles/elev/land/{z}/{y}/{x}.png
```

- 濃さは透過スライダーで調整します
- 「固定ズーム」は標高タイルが実在する最大ズームに合わせてください（産総研のタイルは 15）

計算内容は光源を使わない立体図に変わりましたが、プレフィックスは `hillshade://` のまま
据え置いています。ユーザーが追加済みの地図・エクスポート済みの地図JSON・共有プロジェクトの
設定に既に埋め込まれており、変えると認識されず標高タイルの生の色が表示されるためです。

## 対応する標高タイル

**国土地理院・産総研方式のみ**に対応しています。

```
x = 2^16·R + 2^8·G + B
NoData は 2^23（透明にする）
標高[m] = x < 2^23 ? x/100 : (x − 2^24)/100
```

Mapbox Terrain-RGB や Terrarium 形式には対応していません。

## 陰影の計算方法

MPI赤色立体地図（Kaneda and Chiba 2019）を無彩色化したもので、
**2つの「暗さ」の掛け算**です。

```
MPI  = 各方位(8本)について半径16px以内の最大仰角を求め、その平均[度]
傾斜 = 中央差分による勾配の大きさ[度]

s = clamp(傾斜 / 55°)
m = clamp(MPI / 25°) ^ γ        （γ = 1）
明度 = 255 × (1 − s) × (1 − m)
```

MPI（Morphometric Protection Index、保護指数）は「周囲の地形にどれだけ囲まれているか」
を表します。谷底は周りが高いので各方位の仰角が大きく MPI が大きくなり、
尾根や平坦地は周りが低いか同じなのでほぼ 0 か負になります。

| 地形 | 見え方 |
|---|---|
| 急峻な谷 | 両方効いて最も暗い |
| 急な尾根 | 傾斜だけ効いて中間 |
| 平坦な谷底 | MPIだけ効いて中間 |
| 平坦な尾根・台地 | どちらも効かず白 |

探索半径は画素固定の 16px です。z=14（約 9m/px）で約 145m となり、
MPI赤色立体地図で推奨される実距離 150m とほぼ一致します。画素固定なので
1タイルあたりの計算コストがズームによらず一定になります。

## 実装

| プラットフォーム | 実装 |
|---|---|
| 計算（Web） | `src/utils/terrainShading.ts` |
| タイル生成（Web） | `src/utils/shadingTileProtocol.web.ts`（maplibre の `addProtocol`、内部プロトコル `terrainshade://`） |
| Android | `MapDEMTileProvider.java`（`patches/react-native-maps+1.27.2.patch`） |
| iOS | `AIRGoogleMapDEMTileOverlay.m`（同上） |

3プラットフォームとも同じ計算をしています。**変更するときは3つとも揃えてください。**
移植が正しいことは、同一の合成地形に対する出力を突き合わせて確認しています
（4096画素すべて完全一致）。

Web では maplibre 内蔵の hillshade レイヤは使いません（光源方位に依存するため）。
標高タイルを自前で取得・デコードし、陰影を計算した通常のラスタタイルとして返します。

いずれのプラットフォームでも共通する要点:

- 探索半径のぶんの袖が要るので、1タイル描くのに**周囲8タイルの標高を参照**します。
  デコード済みの標高をキャッシュするので、実質1枚あたり1回の取得で済みます
- NoData と取得失敗は透明にします
- オーバーズーム時は標高が実在する最大ズームで計算してから切り出して拡大します
- **標高タイルの提供範囲には地域差があります。** 産総研の陸域統合DEMは仕様上z19まで
  ですが、実測ではz14が全国、z15は佐渡島・知床・屋久島などで欠け、z16以上は東京都と
  高知県のみでした。要求されたズームで取れないときは粗いズームへ降りて切り出すので、
  「固定ズーム」を高めに設定しても白抜けにはなりません（そのぶん解像度は落ちます）

オフライン用にダウンロードされるのは**陰影の計算結果ではなく生の標高タイル**です。
表示のたびに計算します。

## 注意

- 平坦地は白になります。乗算で重ねる前提の図なので、ベースマップに重ねるより
  単体（透過 0）で背景として使う方が本来の姿です
- ネイティブのパッチを変更したら `npx patch-package react-native-maps
  --exclude '(^|/)(\.gradle|build|\.cxx)/'` で再生成してください。
  除外を付けないと `node_modules` に残ったビルド生成物を巻き込みます
