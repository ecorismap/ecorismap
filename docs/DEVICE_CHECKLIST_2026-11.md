# 実機チェックリスト（2026-11-23 の修正分）

2026-11-23 に入れた修正（写真・タイル・編集・アカウント・3D/眺望・保存の各監査、判断待ち項目、プロジェクト削除のオーナー限定）のうち、単体テストやエミュレーターでは確かめられず、実機（iPhone / Android / Web ブラウザ）で操作しないと分からないものをまとめた。
監査の詳細は `docs/PHOTO_AUDIT_2026-11.md`・`TILE_AUDIT_2026-11.md`・`EDIT_AUDIT_2026-11.md`・`ACCOUNT_AUDIT_2026-11.md`・`TERRAIN_AUDIT_2026-11.md`・`PERSIST_AUDIT_2026-11.md`・`DECISIONS_2026-11.md` を参照。

## 使い方

- **対象ビルド**: 2026-11-23 以降の `main`（`4795dfe3` 以降）から作った TestFlight 版・Google Play 内部テスト版と、Web 本番。
- **準備するもの**
  - テスト用の共有プロジェクト（使い捨てにできるもの。削除系の項目で消える）
  - 2つ以上の組織アカウント: オーナーと、オーナーではない管理者／一般メンバー。削除してよい試験用アカウント1つ（ACCOUNT-11）
  - 写真: iPhone の「高効率」で位置情報付きで撮った HEIC、Android の HEIF（Galaxy など）、数 MB 以上の大きい写真、PNG・WebP の画像ファイル（Web）
  - 地図: PDF 地図、PMTiles（ラスタ URL・ベクタ・数百 MB のファイル）、スタイル JSON、プリセット「特定植物群落」「クマタカ生息適地」、署名付き配信の保護地図
  - 旧版（0.6.x）のデータが残る端末（PHOTO-3・TILES-10）、Android 10 の端末（PHOTO-16）、Firebase コンソールの閲覧権限（PHOTO-13・14）
- **結果の書き方**: 先頭列の □ を ✓（期待どおり）か ✗（違う）に書き換え、✗ のときは「修正番号」列の後ろにメモ（何が起きたか・OS・ビルド番号）を足す。試せなかったものは □ のまま「未」と書く。
- **重要度**: 高＝データが消える・壊れる恐れ、中＝機能が動かない、低＝表示。各表は高→中→低の順。
- ボタン名・メッセージは `src/i18n/ja/translation.json` の日本語表示に合わせている。「（画面名要確認）」「（ボタン名要確認）」は画面で確かめてから操作する。

## エミュレーター・単体テストで確認済みのため除いたもの

Firestore/Storage の Security Rules の可否（`yarn testrules`）、写真の保存パス・名前付け・参照カウントやテンプレート写しの原画コピー、プロジェクト作成〜削除・DEK 共有・共同編集の流れ（`src/lib/__tests__/firebase/e2e_photo_storage`・`e2e_project_flow`・`e2e_project_dek`・`e2e_data_collab`・`e2e_data_photo_copy` の計71件）、属性の型変換・連番採番・絞り込み/ソートの比較・GeoJSON の穴処理・タイル枚数計算などの純粋なロジック（単体テスト）は、この一覧に入れていない。ここに残したのは OS の写真ピッカー・カメラ・Activity 破棄、ネイティブのタイル保存とオフライン表示、地図・3D の描画、実際の画面操作の順序に依存するものだけである。また、タイル配信の 5xx や壊れた応答への対処（M-M3・M-M5・M-M9・M-M16）は実機で再現するのが難しいため、地図設定リスト画面は「地図選択」からの入口がコメントアウトされているため手順にしていない。Web の管理者が設定を保存し直すと共有スタイルの URL が変わる既知の不具合は方針待ち（エミュレーターのテストでも skip）で、このチェックの対象外。
