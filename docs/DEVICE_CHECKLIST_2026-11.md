## エミュレーター・単体テストで確認済みのため除いたもの

Firestore/Storage の Security Rules の可否（`yarn testrules`）、写真の保存パス・名前付け・参照カウントやテンプレート写しの原画コピー、プロジェクト作成〜削除・DEK 共有・共同編集の流れ（`src/lib/__tests__/firebase/e2e_photo_storage`・`e2e_project_flow`・`e2e_project_dek`・`e2e_data_collab`・`e2e_data_photo_copy` の計71件）、属性の型変換・連番採番・絞り込み/ソートの比較・GeoJSON の穴処理・タイル枚数計算などの純粋なロジック（単体テスト）は、この一覧に入れていない。ここに残したのは OS の写真ピッカー・カメラ・Activity 破棄、ネイティブのタイル保存とオフライン表示、地図・3D の描画、実際の画面操作の順序に依存するものだけである。また、タイル配信の 5xx や壊れた応答への対処（M-M3・M-M5・M-M9・M-M16）は実機で再現するのが難しいため、地図設定リスト画面は「地図選択」からの入口がコメントアウトされているため手順にしていない。Web の管理者が設定を保存し直すと共有スタイルの URL が変わる既知の不具合は方針待ち（エミュレーターのテストでも skip）で、このチェックの対象外。
